# Provenance and attribution

This is Ariel M. Williams's accepted original-symmetric finite certificate,
prepared as an additive v1.4.0 verification package. All earlier release
certificates, checkers, declarations, tags and DOI versions remain intact.
Implementation and internal proof/rejection reviews used OpenAI Codex;
that assistance is not external human refereeing or a proof-kernel check.
Public code and certificate data retain the repository's MIT license.

Hou--Zhao supply the original finite vector-valued smoothing framework and
joint component-boundary quadratic-program viewpoint. Finite box filtering,
weighted Gram duality, equality-constrained least-norm projection and residual
repair are inherited standard tools. Akwei's asymmetric ramp, renewal/floor
analysis and already-reported approximate finite-grid formulas motivate the
comparison; their pattern/rate are not claimed as new discoveries. Stephen
Wu/wustep's historical q2 remains an attributed external benchmark. See the
root development/theorem note and `PROOF.md` for the versioned references.

The fixed mathematical data have n=1024, L=8 and multiplier precision 80.
Only the first affine multiplier u0 from the accepted archived run is needed.
At the winning theta zero, the flat cover vector and repair depend solely
on the fixed operators and weights, not on the asymmetric boundary or common
core. No optimizer, source profile, private correspondence or full research
review is copied into this package. The public replay reconstructs actual
arrays and verifies them directly.
